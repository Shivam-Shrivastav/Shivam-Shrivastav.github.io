Song Recommendation System
A content-based recommender that suggests songs matching any Spotify playlist using the Spotify API and cosine similarity.
Project Details
The app pulls a user's playlist through the Spotify API, extracts audio features for each track, and compares them against a Kaggle Spotify songs dataset. It recommends the closest matches by cosine similarity, making suggestions feel like a natural extension of the user's taste.
This was one of my early ML projects and a practical introduction to recommendation systems, API integration, and vector similarity.
Tech: Python, Spotify API, Jupyter Notebook, scikit-learn, pandas.
